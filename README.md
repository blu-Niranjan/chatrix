# 💬 Real-Time Chat App Using Django Channels

A real-time web-based chat application built with **Django**, **Channels**, and **WebSockets**. This app enables users to join chat rooms and exchange messages instantly—similar to how WhatsApp works.

---

## 🚀 Features

- 🔁 Real-time bi-directional messaging with **WebSockets**
- 👥 Support for dynamic chat rooms (e.g., `/chat/general/`, `/chat/random/`)
- ⚡ Built using **Django Channels** and **ASGI**
- 💡 JavaScript-powered frontend to handle live messaging
- 🧪 In-memory channel layer for testing (easy to upgrade to Redis)
- 🎯 Minimal UI for testing functionality (can be customized later)

---

## 🛠️ Tech Stack

- **Python 3.x**
- **Django 5.x**
- **Django Channels**
- **ASGI**
- **HTML5, CSS3, JavaScript**
- **SQLite3** (default, replaceable with PostgreSQL)
